2. 視覺主題與 CSS 變數設計
全站以 Pure Black OLED (純黑極簡) 為預設視覺風格，降低高螢幕亮度對眼睛的負擔，並運用高對比天藍色 (#38bdf8) 突顯重點資訊：

CSS
:root {
    /* 純黑預設主題 (Pure Black Theme) */
    --bg-primary: #000000;          /* 全站主背景 */
    --bg-secondary: #121212;        /* 卡片與內容區塊背景 */
    --bg-card: #1e1e1e;             /* 浮動卡片 */
    --text-primary: #ffffff;        /* 主文字（極高對比白色） */
    --text-secondary: #a1a1aa;      /* 次要文字（柔和灰色） */
    --accent-blue: #38bdf8;         /* 強調視覺色 (Sky Blue) */
    --nav-bg: rgba(0, 0, 0, 0.85);  /* 導覽列霧面半透明黑 */
    --border-color: rgba(255, 255, 255, 0.12);
}

/* 亮色主題適配 (Light Mode Fallback) */
body.light-theme {
    --bg-primary: #f8fafc;
    --bg-secondary: #ffffff;
    --text-primary: #0f172a;
    --text-secondary: #334155;
    --accent-blue: #0284c7;
    --nav-bg: rgba(255, 255, 255, 0.95);
    --border-color: #e2e8f0;
}
3. 多國語系 (i18n) 與主題切換邏輯
本站不依賴第三方重型框架，採原生 Vanilla JS 實現高效的 UI 狀態管理：

語系切換：DOM 節點配置 data-zh="..." 與 data-en="..."，切換時由 js/main.js 動態更新 textContent。

中文姓名恆定保護：Hero 區塊的主標題 <h1>江育霖</h1> 排除 data-en 屬性，確保在切換至英文版時，中文姓名依然完整保留。

狀態持久化：使用 localStorage.setItem('theme') 與 localStorage.setItem('lang') 記住使用者選擇。

Mobile ( <= 768px )：

🛠️ 本地開發與 GitHub Pages 部署指南
1. 本地預覽 (Local Development)
將專案 Clone 至本地：

Bash
git clone https://github.com/lp911205-CHIANG/tonychiang.git
使用 VS Code 的 Live Server 套件開啟 index.html 即可進行即時預覽。

2. GitHub Pages 發布步驟與注意事項
目錄與檔案命名規範：Linux 伺服器嚴格區分大小寫，資料夾名稱務必維持全小寫：css/、js/、images/。

強迫刷新快取 (Cache Busting)：當修改完 CSS/JS 發布後，若瀏覽器未即時更新，請於 index.html 引入處加入版本查詢字串：

HTML
<link rel="stylesheet" href="css/style.css?v=2">
<script src="js/main.js?v=2"></script>
GitHub Pages 啟用設定：
進入倉庫 Settings ➔ Pages ➔ Source 選擇 Deploy from a branch ➔ Branch 選擇 main / / (root) ➔ 點擊 Save。
