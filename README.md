## 📸 照片上傳說明

網站目前指向以下照片路徑，請自行上傳：

1. **profile.jpg** - 個人頭像（建議280x280px，圓形）
2. **research1.jpg** - 智慧健康照護相關圖片
3. **research2.jpg** - 決策模型相關圖片
4. **research3.jpg** - 虛擬人相關圖片

**上傳步驟**：
1. 進入 GitHub 倉庫
2. 建立 `assets/images/` 資料夾（若不存在）
3. 上傳照片檔案
4. 自動更新網站

## 📱 響應式設計

- **桌面** (1200px以上)：完整3欄佈局
- **平板** (768px-1199px)：2欄佈局
- **手機** (480px-767px)：單欄佈局 + 漢堡菜單
- **超小屏** (360px以下)：最小化設計

## ✏️ 如何編輯

### 修改文字內容
1. 編輯 `index.html`
2. 推送到 GitHub
3. 自動發佈更新

### 修改樣式
1. 編輯 `css/style.css` 或 `css/responsive.css`
2. 推送到 GitHub
3. 刷新瀏覽器查看效果

### 添加功能
1. 編輯 `js/main.js`
2. 推送到 GitHub
3. 刷新瀏覽器測試
