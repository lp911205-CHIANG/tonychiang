## 🚀 如何使用

### 1. 啟用 GitHub Pages
1. 進入倉庫設定 (Settings)
2. 選擇 Pages
3. 選擇 main 分支作為發布來源
4. 保存設定

### 2. 本地開發

```bash
# 克隆倉庫
git clone https://github.com/lp911205-CHIANG/tonychiang.git

# 進入目錄
cd tonychiang

# 用瀏覽器打開 index.html
# 或使用本地伺服器
python -m http.server 8000
# 訪問 http://localhost:8000
```

## ✏️ 如何更新內容

1. **編輯 index.html**：修改正文內容
2. **更新樣式**：編輯 `css/style.css` 或 `css/responsive.css`
3. **修改功能**：編輯 `js/main.js`
4. 提交變更並推送到 GitHub
